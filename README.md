## 📄 Research

**Cow Posture Detection in Cattle** was presented at the EEECS Thailand Conference, Chiang Mai 2025. It uses YOLOv8 and YOLOv11 to detect four cow postures (standing, lying, grazing, mounting) and reached **mAP@50 of 0.888** with YOLOv8s. It supports automated estrus detection and livestock health monitoring, and it grew into my final year project.
